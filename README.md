# 提示词反推

从图片提炼可复用的画风提示词、可替换内容的完整样板，也支持还原画面、
套用新主题及导出 JSON 风格卡片。结果是对可见画面的重新描述，不能找回原始提示词。

## 准备与安装

需要具备看图能力、可读取本机文件的助手。将整个目录放入宿主支持的技能目录，
按宿主方式刷新；也可直接让助手读取本目录的 SKILL.md。
仅分析图片不需要 API Key，不调用图片生成服务；对话模型本身的费用由宿主决定。

## 使用

附上图片或给出可访问的本机路径，然后说：

```text
使用 $image-to-prompt 提取这张图的画风，给我三段可换内容的样板。
使用 $image-to-prompt 用这个画风写一段雨夜书店的提示词，只要提示词。
使用 $image-to-prompt 尽量还原这张图的构图。
使用 $image-to-prompt 把这个风格导出为 JSON 卡片。
```

默认中文，支持英文或中英双语。样板中的 `【具体内容】` 可以替换，
保留原文也能直接使用。只有明确要求出图时才衔接可用的生成工具；
图片生成可能上传数据并收费。

## 配置与输出

`config/` 无需配置，可以为空。通常直接在对话交付提示词；要求保存时写到指定位置。
JSON 卡片格式见 [风格卡片结构](references/style-card.schema.json)。
看不到图片时会请求补图，不依据文件名猜测。不会默认把参考图片上传给生成服务。

## 文件分工

SKILL.md 是助手执行入口；references 包含写作规则和卡片格式；agents/openai.yaml
提供中文界面信息。公开分享前需确认所采用资料的分发依据；本目录不附加整体授权声明。
